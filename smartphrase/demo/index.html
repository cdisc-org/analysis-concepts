AC/DC Smartphrase — Proof-of-Concept Demos

Three interaction modes over a single worked example: the CDISC Pilot primary efficacy analysis (change from baseline in ADAS-Cog(11) at Week 24, ANCOVA). Each demo is self-contained — open it directly in a browser, no server required.

Inspect

Hover any smartphrase in a finished SAP passage to reveal the AC/DC metadata behind it — sp-oid, role, bound concepts and grounding IRIs. Read-only.

Author & bind

Edit the AC/DC instance and watch the SAP prose resolve live; the model metadata is rebuilt from the same bindings. The bidirectional authoring surface.

Provenance

Click a smartphrase to follow its resolution chain down to the data: DataConcept → ADaM Class Variable → study variable → physical dataset.
