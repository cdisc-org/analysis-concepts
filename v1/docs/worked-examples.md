# Worked examples

Two studies are carried through every layer. Both come from the SmartPhrase proof of concept on
`estimands_01`; here they are expressed in the candidate v1 model and checked by its validator.
The sentences and tables below are produced by the reference tools from the committed files
(`v1/tools/render.py`, `v1/tools/resolve.py`), and regenerated by `v1/tools/gen_examples.py`.

Identifiers marked `illustrative` in the study files (USDM, ARS and Biomedical Concept identifiers) are
plausible stand-ins, not registered identifiers.

## CDISC Pilot (CDISCPILOT01)

Xanomeline in mild to moderate Alzheimer's disease. Four analyses of change from baseline, all instances of one template, `T.CFB_ANCOVA`. The study has no source document, so document anchoring does not apply.

File: `v1/studies/cdiscpilot01/analysis_set.json`

| `AC.SEC.NPIX` | `T.CFB_ANCOVA` | `EST.SECONDARY.NPIX` | MainEstimator | none in scope |

### Analysis to derivation, and specification to data

```
AC.PRIMARY.ADASCOG
  derivations, in order: DC.BASELINE.ADASCOG11 -> DC.LOCF.ADASCOG11 -> DC.CHG.ADASCOG11.WK24.LOCF
  response      C.Change         <- ADQSADAS.CHG WHERE PARAMCD = 'ACTOT' AND AVISITN = 24 AND ITTFL = 'Y'
  covariate     C.Measure        <- ADQSADAS.BASE WHERE PARAMCD = 'ACTOT' AND AVISITN = 24 AND ITTFL = 'Y'   [baseline value carried on the analysis record]
  fixed_effect  C.Treatment      <- TRTP
```

```
AC.SENS.ADASCOG.TP
  derivations, in order: DC.BASELINE.ADASCOG11 -> DC.CHG.ADASCOG11.WK24
  response      C.Change         <- ADQSADAS.CHG WHERE PARAMCD = 'ACTOT' AND AVISITN = 24 AND ITTFL = 'Y'
  covariate     C.Measure        <- ADQSADAS.BASE WHERE PARAMCD = 'ACTOT' AND AVISITN = 24 AND ITTFL = 'Y'   [baseline value carried on the analysis record]
  fixed_effect  C.Treatment      <- TRTP
```

The primary analysis handles treatment discontinuation with the hypothetical strategy, implemented by
`T.LOCF_Imputation`, so its change from baseline is taken from LOCF-imputed data. The sensitivity analysis
handles the same event with the treatment-policy strategy and reads the data as observed. That is a
different estimand (`EST.SENS.TP`), and a different derivation chain.

## PrE0102

Fulvestrant plus everolimus in metastatic breast cancer. Four descriptive time-to-event analyses, all instances of `T.PFS_KaplanMeier`, each anchored to quoted passages of the study's statistical analysis plan.

File: `v1/studies/pre0102/analysis_set.json`

### Analysis Concepts

| Analysis Concept | Template | Addresses estimand | Role | Intercurrent events handled |
| --- | --- | --- | --- | --- |
| `AC.PRIMARY.PFS` | `T.PFS_KaplanMeier` | `EST.PFS` | MainEstimator | ICE.TOX_DISCONT: TreatmentPolicy |
| `AC.SENS.PFS.ITT` | `T.PFS_KaplanMeier` | `EST.PFS` | SensitivityAnalysis | ICE.TOX_DISCONT: TreatmentPolicy |
| `AC.SEC.OS` | `T.PFS_KaplanMeier` | `EST.OS` | MainEstimator | none in scope |
| `AC.SEC.TTP` | `T.PFS_KaplanMeier` | `EST.TTP` | MainEstimator | none in scope |

### Model to text

The sentence each Analysis Concept generates, in the three languages that have a language pack.

**AC.PRIMARY.PFS** (en)

> Time to disease progression or death (PFS) in the eligible, treated population comparing treatment groups, regardless of discontinuation of everolimus for suspected toxicity, using Kaplan-Meier estimation with 90% confidence intervals, censoring subjects lost to follow-up, displayed as Kaplan-Meier survival curves by treatment arm, summarised as the median time to event, will be assessed as the primary analysis.

The other analyses, in English:

- `AC.SENS.PFS.ITT`: Time to disease progression or death (PFS) in the intent-to-treat population comparing treatment groups, regardless of discontinuation of everolimus for suspected toxicity, using Kaplan-Meier estimation with 90% confidence intervals, censoring subjects lost to follow-up, displayed as Kaplan-Meier survival curves by treatment arm, summarised as the median time to event, will be assessed as a sensitivity analysis.
- `AC.SEC.OS`: Time to death from any cause (OS) in the eligible, treated population comparing treatment groups using Kaplan-Meier estimation with 90% confidence intervals, censoring subjects lost to follow-up, displayed as Kaplan-Meier survival curves by treatment arm, summarised as the median time to event, will be assessed as a secondary analysis.
- `AC.SEC.TTP`: Time to disease progression (TTP) in the eligible, treated population comparing treatment groups using Kaplan-Meier estimation with 90% confidence intervals, censoring subjects lost to follow-up, summarised as the median time to event, will be assessed as a secondary analysis.

### Analysis to derivation, and specification to data

```
AC.PRIMARY.PFS
  derivations, in order: (none in the library for time-to-event data)
  time          C.TimeToEvent    <- ADTTE.AVAL WHERE PARAMCD = 'PFS' AND EFFIFL = 'Y'
  event         C.Flag           <- ADTTE.CNSR WHERE PARAMCD = 'PFS' AND EFFIFL = 'Y'
  fixed_effect  C.Treatment      <- TRTP
```

```
AC.SENS.PFS.ITT
  derivations, in order: (none in the library for time-to-event data)
  time          C.TimeToEvent    <- ADTTE.AVAL WHERE PARAMCD = 'PFS' AND ITTFL = 'Y'
  event         C.Flag           <- ADTTE.CNSR WHERE PARAMCD = 'PFS' AND ITTFL = 'Y'
  fixed_effect  C.Treatment      <- TRTP
```

`AVAL` carries time to event only where `PARAMCD` is `PFS`. The library's class-level binding marks
`AVAL` as parameter-dependent, and the study's value-level binding resolves it. The same template serves
progression-free survival, overall survival and time to progression; only the event changes.

### Anchored to the source document

Every use of a phrase is tied to the passage of the plan that licenses it. For example, in `AC.PRIMARY.PFS`:

- `SP_METHOD_KM` — section 7.7.2: "Median time and 90% confidence interval for PFS, TTP, and OS will be summarized for all eligible, treated subjects by treatment arm using Kaplan-Meier estimates."
- `SP_CONFIDENCE_LEVEL` — section 7.7.2: "Median time and 90% confidence interval for PFS, TTP, and OS will be summarized for all eligible, treated subjects by treatment arm using Kaplan-Meier estimates."
- `SP_ICE_TREATMENT_POLICY` — section 4.3: "All subjects who have discontinued protocol therapy will be followed for survival and for progression, even if protocol therapy was discontinued because of toxicity or for other reasons."
- `SP_CENSOR_LTFU` — section 7.7.2: "Subjects who are lost to follow-up are censored at the time of last tumor assessment for TTP and PFS"
- `SP_KM_CURVES` — section 7.7.2: "In addition to the summary table, PFS and OS will be displayed by treatment arm using Kaplan-Meier survival curves."
- `SP_SUMMARY_MEASURE` — section 7.7.2: "Median time and 90% confidence interval for PFS, TTP, and OS will be summarized for all eligible, treated subjects by treatment arm using Kaplan-Meier estimates."
